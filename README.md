# 🎨 Drawables Shapes Project (Java GUI)

An educational **Java GUI** project for drawing and managing geometric shapes.  
This project focuses on applying object-oriented programming concepts in a graphical environment.

---

## 📌 Features
- Drawing basic geometric shapes
- Simple GUI interaction
- Shape rendering using OOP principles

---

## 🧠 Concepts Used
- Object-Oriented Programming (OOP)
- Inheritance & Polymorphism
- Abstraction

---

## 🛠 Technologies
- Java
- Java GUI (Swing / AWT)
- Git & GitHub
